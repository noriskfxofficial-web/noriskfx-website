كيف بتعدل الموقع من الأدمن؟

بهذه النسخة، إذا شغّلت backend تنحفظ التعديلات بقاعدة بيانات JSON وتظهر لكل الزوار بعد refresh. وإذا فتحتها static فقط، بيشتغل fallback محلي على نفس المتصفح.

  1. عدّل النصوص أو رموز TradingView.
  2. اضغط Save website changes.
  3. ارجع على الصفحة الرئيسية واعمل refresh.
  4. للإنتاج، شغّل السيرفر عبر npm start واستعمل دومين مع HTTPS.
مهم: صار في backend مبدئي مع Login وDatabase. قبل النشر العلني لازم تغيّر كلمة السر والـ JWT secret وتستعمل HTTPS.
